# Security

If you find a security problem in midipiano.app (the web app or its API), please report it privately. Do not open a public issue or discussion for it.

- Preferred: use GitHub's private vulnerability reporting on this repository ("Report a vulnerability" under the Security tab).
- Or write to contact@midipiano.app.

Say what you found, how to reproduce it and what you think the impact is. You will get an answer, and a fix if it is confirmed. There is no bug bounty.
